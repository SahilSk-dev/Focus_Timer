Install on Android
Sideload the Focus Timer APK in about a minute. It runs next to the web app and syncs with the same Google account.
  1. 1
    Download the APK

    Tap Download APK. If Chrome warns that this file type can harm your device, choose Download anyway.

  2. 2
    Open the downloaded file

    Open Downloads and tap focus-timer-debug.apk. Android may ask which app should handle it — choose your browser or file manager.

  3. 3
    Allow installs from this source

    If prompted, enable Install unknown apps for the browser or file manager, then return to the installer.

  4. 4
    Install and open

    Tap Install. When it finishes, open Focus Timer and sign in to sync your sessions.

Updating: download the latest APK and install it over the old version. Your history and preferences are kept. Browse all Android releases.
Install blocked? Check Settings → Apps → Special access → Install unknown apps, allow your browser, then try again.
